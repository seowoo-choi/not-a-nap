# NOT A NAP 플레이어 카피 가이드

게임 화면의 문장은 아래 네 가지 역할만 맡는다.

1. 지금 벌어진 사건을 보여준다.
2. 플레이어가 할 일을 알려준다.
3. 행동의 결과와 비용을 돌려준다.
4. 반복한 행동이 다음 밤의 규칙으로 남는다는 사실을 기억시킨다.

## 벤치마크에서 가져온 원칙

- 가족 영화처럼 첫 문장에 사건을 둔다. 세계관 설명보다 `등이 닿았다. 눈이 번쩍.`이 먼저다.
- 캐릭터의 감정은 행동으로 보여준다. `눈을 떴다`, `손을 입으로 가져간다`, `몸이 움찔했다`처럼 쓴다.
- 아기 소재 코미디처럼 처음부터 임무와 반전을 붙인다. `잠든 아기` 다음에 바로 `눕히자 깨어남`을 보여준다.
- 게임 문장은 동사로 끝낸다. `특징 섞기`, `원인 찾기`, `기저귀 갈기`, `오늘 밤 버티기`처럼 다음 입력을 예고한다.
- 버튼은 누른 뒤 일어날 일을 그대로 말한다. 분위기만 있는 문장은 버튼에 쓰지 않는다.
- 한 화면에 한 목소리만 둔다. 게임 규칙, 육아 안내문, 감성 에세이를 한 문단에 섞지 않는다.

참고한 공식 소개 문구와 장면 구성:

- Pixar `Bao`: 가족의 감정은 설명보다 행동과 사건으로 먼저 보여준다. <https://www.pixar.com/bao>
- DreamWorks `The Boss Baby`: 아기라는 소재를 즉시 임무와 코미디로 바꿔, 첫 소개에서 갈등과 팀의 목표를 함께 제시한다. <https://www.dreamworks.com/movies/the-boss-baby>
- DreamWorks `The Boss Baby: Get That Baby!`: 인터랙티브 콘텐츠는 처음부터 플레이어의 능력을 시험하는 문장으로 참여를 요청한다. <https://www.dreamworks.com/shows/the-boss-baby-get-that-baby>
- Nintendo `Yoshi's Island`: 아기를 지킨다는 목표와 실패 조건을 즉시 이해시킨다. <https://www.nintendo.com/en-za/Games/Game-Boy-Advance/Yoshi-s-Island-Super-Mario-Advance-3-267640.html>
- Nintendo `Princess Peach: Showtime!`: 버튼과 역할 문구는 플레이어가 곧 하게 될 행동을 직접 말한다. <https://www.nintendo.com/us/store/products/princess-peach-showtime-switch/>

## 목소리

- 제목과 사건: 짧은 서술형. 긴박하지만 과장하지 않는다.
- 선택지와 버튼: 즉시 이해되는 행동형.
- 행동 결과: 무엇이 바뀌었는지 먼저, 이유는 다음 문장에.
- 밤의 기록과 엔딩: 플레이 중보다 따뜻해도 되지만 반드시 실제 플레이 결과를 포함한다.

## 쓰지 않는 표현

| 쓰지 않음 | 이유 | 대신 사용 |
|---|---|---|
| 무료로 뽑아보세요 | 광고·가챠처럼 들림 | 특징 섞기 |
| 정답보다 서로의 리듬 | 추상적이고 게임 목표가 안 보임 | 최장 수면 00분 · 깨어남 0회 |
| 서로를 알아가는 밤 | 어떤 플레이인지 설명하지 못함 | 울기 전에 원인을 찾아라 |
| 소품을 진열대에 올리세요 | 준비 화면의 목적이 흐림 | 오늘 밤 쓸 물건 3개를 고르세요 |
| 보호자도 돌봄이 필요해요 | 결과와 다음 행동이 불명확함 | 체력이 바닥났다 · 먼저 숨 고르기 |
| 아기를 직접 만져 돌봐주세요 | 웹페이지 안내처럼 들림 | 아기를 눌러 행동을 고르세요 |
| 반짝이는 오브젝트 | 개발 용어가 노출됨 | 필요한 물건 |
| 능력치에는 영향 없음 | 몰입을 끊는 시스템 공지 | 화면에서 삭제하고 선택 결과만 보여주기 |

## 대표 화면의 확정 문구

### 첫 30초

- `02:47`
- `드디어 잠들었다.`
- `이제 침대에 내려놓기만 하면 된다.`
- `조심히 내려놓기`
- `등이 닿았다. 눈이 번쩍.`
- `NOT A NAP`
- `눕히면 깬다`
- `아침 6시까지 함께 버텨라.`
- `깊은 잠 · 체력 · 맨손 눕히기 중 둘을 지켜라.`
- `오늘 밤 버티기`

### 아기 설정

- `우리 아기는 누구를 닮았을까?`
- `엄마와 아빠의 입 모양과 목소리를 골라 주세요`
- `특징 섞기` / `다시 섞기`
- `이 아기로 시작하기`
- `바로 시작`

### 첫 판단

- `아기는 왜 보채는 걸까?`
- `배가 고픈가?`
- `기저귀가 불편한가?`
- `졸린가?`
- 성공: `맞았다. 배가 고팠다.`
- 실패: `울음이 한 단계 커졌다.`

### 플레이

- 기본 질문: `왜 보채는 걸까?`
- 관찰 열기: `아기 살펴보기`
- 행동 선택: `아기를 눌러 행동을 고르세요`
- 결과 제목: `행동 결과`
- 상태 자원: `연속 수면`, `보호자 체력`, `집중력`

### 기저귀

- `기저귀 확인 · 1분 · 체력 -1`
- 깨끗함: `기저귀는 깨끗해요. 75분 동안 다시 확인하지 않아도 돼요.`
- 소변: `기저귀가 젖었어요. 갈고 싸서 버립니다.`
- `소변 기저귀 갈기 · 7분 · 체력 -2`
- `싸서 버리기 · 2분 · 체력 -1` (확인부터 총 10분 · 체력 -4)
- 대변: `대변 기저귀예요. 처리한 뒤 수유 전에 손을 씻어야 합니다.`
- `대변 기저귀 갈기 · 13분 · 체력 -4`
- `싸서 버리기 · 4분 · 체력 -2`
- `손 씻기 · 2분 · 체력 -1` (확인부터 총 20분 · 체력 -8)

### 밤의 기록

- `밤의 결과`
- `처음 발견한 신호`
- `내가 선택한 행동`
- `다음 밤에 바뀌는 것`
- `오늘 형성된 습관`

## 감사 범위

플레이어에게 노출될 수 있는 한국어 문구는 다음 런타임 소스에서 확인한다.

- `Assets/Scripts/App/GameBootstrap.cs`
- `Assets/Scripts/Presentation/PresentationCopyMapper.cs`
- `Assets/Scripts/Presentation/GameSessionPresenter.cs`
- `Assets/Scripts/Core/Models/ItemDef.cs`
- `Assets/Scripts/Core/Models/Temperament.cs`
- `Assets/Scripts/Core/Resolvers/*.cs`의 로그와 피드백
- `Assets/WebGLTemplates/NotANap/index.html`

새 문구를 추가할 때는 `무료`, `정답보다`, `알아가는 밤`, `오브젝트`, `직접 만져`, `진열대`가 플레이어 문구에 다시 들어오지 않았는지 검색한다.
