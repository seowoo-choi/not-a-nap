## 2026-07-26 관계 중심 플레이 개편

Figma 댓글 이후 제품 논의에서 나온 방향을 기존 V6 싱크 보드에 추가한다. 별도 보드를 만들지 않는다.

| 제품 방향 | 이번 해커톤 반영 | 제품 확장 |
|---|---|---|
| 첫째 밤 뒤 둘째 밤이 시작되지 않음 | 오버레이 닫기→일지→둘째 밤 준비→둘째 밤 PLAY 전체 경로 회귀 테스트 | 실제 WebGL 배포에서도 동일 경로 확인 |
| 표정 외 입·손·호흡·몸짓 신호 | 기존 `ObservationSignalId`를 PLAY 문장·행동 결과에 노출 | 신호별 전용 2프레임 아트 |
| 주방 물품을 가지러 가는 시간 | 분유 준비 결과에 `주방` 위치와 경과 분 표시, 아기 상태도 계속 진행 | 자유 이동은 스코프 밖 |
| 영아 목 받치기 | 맨손 안기·아기띠에 `HeadSupported` 안전 상태 연결 | 자세 미니게임은 스코프 밖 |
| 실패 공포 대신 아기와 소통 | 숨 고르고 신호 기다리기, 마음의 여유, 학습 중심 결과 문구 | 장기 성장 기록 |
| 엄마의 밤 이해 | 육아일지에 보호자 성장과 엄마 이해 문장 | 마미톡 공유 카드 |

| 마미톡·브랜드·광고 | 공유 카드 문안과 안전 원칙만 반영 | SDK·브랜드 계약·광고 표기·심사 후 별도 구현 |
| 집 지도와 직접 이동 | 현재 방을 보호자 초점으로 크게 표시, 우측 상단 3칸 미니맵, WASD/미니맵 클릭으로 방 사이 2–3분 이동, 반투명 상태·행동 HUD | 3D 자유 보행·다층 주택은 스코프 밖 |

### 집 지도 개발 계약

- `HomeLocation`: `Nursery / Kitchen / Bathroom`.
- 아기를 안지 않았다면 아기는 아기방에 남고 보호자만 이동한다.
- `Held=true`라면 아기 위치는 보호자 위치와 같고 이동 결과에 `BabyAccompanied=true`가 기록된다.
- 아기방↔주방, 아기방↔욕실은 2분, 주방↔욕실은 3분이다. 이동 중 허기·울음·수면·예약 각성은 멈추지 않는다.
- 분유 준비와 소독은 주방, 환경 조절과 눕히기는 아기방에서만 가능하다.
- 욕실에 처음 가면 탕온계를 챙기며, 아기 체온 확인은 탕온계를 가진 뒤 아기와 같은 위치에서만 가능하다.
- 지도 위 상태 카드는 위치와 관계없이 아기의 현재 신호를 계속 보여준다.
- 메인 장면은 현재 방을 보호자 초점으로 보여주며 전체 구조와 보호자·아기 위치는 우측 상단 미니맵에 표시한다.
- WASD는 자유 보행 좌표가 아니라 세 방 사이의 결정론적 이동 입력이다. 상태 카드와 행동 버튼은 배경을 가리지 않는 반투명 HUD로 띄운다.
