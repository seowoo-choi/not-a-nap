# 결정 등록부

## [확정]

- Unity 6000.3.20f1
- Input System Package만 사용 (`activeInputHandler: 1`)
- Web 플랫폼 빌드
- 결정론적 순수 C# Core와 주입식 `IRandomSource`
- AI는 서술 전용이며 수치·확률·기억·이벤트·승패·엔딩 판정에 관여하지 않음
- AI가 없거나 응답이 잘못되어도 규칙 기반 폴백 사용

## [확정된 설계 원칙]

- 과거 행동과 규칙 결과는 가치중립적인 Trace를 남길 수 있음
- Trace 자체에는 Good/Bad 속성을 두지 않음
- 같은 Trace도 Trigger Event와 현재 Context 조합에 따라 Positive, Negative, Neutral 결과가 될 수 있음
- 동일 seed + 동일 입력·Trace·Context는 동일한 미래 이벤트와 발생 시점을 만듦
- AI는 Trace 생성, Future Event 선택, Context 판정과 결과에 개입하지 않음

## [현재 유지하지만 변경 가능]

- 3밤 구조, 밤당 9개 소비 턴
- 기질 3종, 아이템 5종, 엔딩 6종
- 백일째 밤의 3개 중 2개 승리 조건
- 인수인계, 활성수면, 엄마 깨우기, 05:58 최종 도전
- 기존 `MemoryState` 수치형 습관 구조
- V1의 9개 1시간 턴 API는 저장·Presentation 호환 계층으로 유지

## [V2 Core 규칙]

- 밤은 21:00~06:00의 540분 동안 계속되며 눕히기 성공은 밤 종료가 아니라 수면 구간의 일부다.
- 새벽 평가는 최장 연속 수면, 총 수면, 각성, 진단, 안전 지표를 설정 임계값으로 판정한다.
- 잠든 뒤에도 주입된 RNG로 각성 원인과 시점을 예약할 수 있다.
- 수면 단계, 진단, 환경 확인, 단계형 수유 준비는 Core의 구조화된 상태와 결과로 제공한다.
- 의료 권장 범위와 수유량은 Core Resolver에 상수로 확정하지 않고 설정 공급자가 제공한다.
- 외형 ID 및 성별 외형은 기질·능력 modifier와 독립이다.
- Vaccination modifier는 콘텐츠 문구나 진단 없이 규칙 배율만 제공하는 첫 수직 슬라이스다.

## [2026-07-21 코드 정합화 결정]

- 내부 밤 평가는 기존 `NightGrade.S/A/B/C/D`를 유지하고 통잠·긴잠·조각잠·백야는 표시 문구로 매핑한다.
- 제한시간 기본값은 현재 설정의 20초를 첫 플레이테스트 기준으로 사용한다. 8초·12초 문구는 폐기한다.
- 기저귀 첫 확인은 실제 원인이 기저귀가 아니어도 오판으로 세지 않는 무해한 배제 검사다.
- 현재 균등 무작위 `WakeScheduler`는 임시 구현이며 Hunger·환경·수면 단계·modifier 기반 가중치로 교체한다.
- V2 아이템은 실제 효과 또는 정보 게이트가 연결된 것만 Setup에 노출한다.
- 세 밤 Memory/Ending이 연결되기 전에는 전체 제품 루프 완료로 보지 않는다.

현재 수치와 목록은 호환 기본값일 뿐 최종 기획 확정이 아니다. 승리 임계값과 `requiredCount`는 `VictoryRuleDefinition`, 기억 임계값과 초기 상태는 `GameBalanceConfig`, 미확정 기능은 `FeatureFlags`에서 교체한다.

## [2026-08-11 플레이테스트 반영 결정]

플레이테스트에서 "아이템 효과를 알 수 없다 / 집중력이 어디 쓰이는지 모르겠다 /
튜토리얼이 정답 맞히기다"라는 지적이 나와 아래를 확정했다.

### 아이템 문구는 형용사가 아니라 엔진 수치로 적는다

`ItemDef`는 `Role`(정체성 한 줄) · `Effects`(수치 목록) · `Cost`(시간·체력·횟수) ·
`Side`(대가)로 나눈다. "더 빨리 진정시킵니다" 같은 표현은 금지한다. 문구와 Resolver의
수치가 어긋나면 플레이어는 아이템을 고를 근거를 잃는다.

### 백색소음기는 달래는 물건이 아니라 잠을 이어 주는 물건이다

- 폐기: 켜 둔 동안 분당 진정 +0.4 (9시간이면 +216 → "켜 두면 돌보지 않아도 된다")
- 확정: 진정 효과 0 / 잠든 뒤 다음 각성까지 `NoiseWakeDelayBonusMinutes`(25분) 추가 /
  외부 소음 각성을 `NoiseExternalWakeGuard`(0.6) 확률로 차단
- 두 효과 모두 `NoiseHab` 습관화에 비례해 감소한다. 습관화는 밤 시작 시
  `V2NightState.NoiseHabituation`에 스냅샷해 각성 예약에서도 결정론적으로 쓴다.
- 효과를 증명할 자리로 밤당 1회 외부 소음 돌발을 추가한다
  (둘째 밤 경과 150분 초인종, 백일째 밤 330분 윗집 소리). 자고 있을 때만 판정한다.

### 아기띠는 V2에서 실제 이득을 갖는다

안고 준비할 때의 추가 체력 소모(`HoldPreparingExtraStaminaCost`)를 0으로 만들고,
착용 중에는 울음 상승에 `CarrierCryMultiplier`(0.55)를 곱한다.

### 보호자 집중력을 폐기하고 아기 기분을 화면에 세운다

`CaregiverComposure`는 숨 고르기로만 오르고 어떤 판정에도 쓰이지 않는 死수치였다.
제거하고, 대신 `BabyMoodResolver`가 진정도·울음 세기·배고픔에서 파생하는
아기 기분(0~100)과 등급 라벨을 제공한다. 상태를 바꾸지 않는 표시 전용 파생값이다.

### 아기 상태는 아기 곁에 있을 때만 보이고, 베이비 모니터가 유일한 예외다

기존에는 어느 방에 있든 진정도·울음·배고픔이 늘 보였다. 그래서 모니터는 2분과
체력 1을 쓰고 분위기 문장만 돌려주는, 챙길 이유가 없는 물건이었다. 확정:

- `BabyStateVisible` = 아기를 안고 있거나 아기방에 있을 때, 또는
  마지막 모니터 확인이 `MonitorReadFreshMinutes`(30분) 이내일 때
- 닫혀 있으면 수면 단계·신호·기분·진정·울음·배고픔을 모두 감추고 "확인 불가"만 남긴다
- 모니터가 없으면 주방·욕실에서는 어떤 수단으로도 아기 상태를 알 수 없다
- 연속 수면·보호자 체력·방 온습도는 아기를 보지 않아도 알 수 있으므로 계속 노출한다

### 아기 상태는 절대 수치가 아니라 경과 시간으로 읽는다

밤 돌봄의 판단은 "진정도가 몇이냐"가 아니라 "마지막으로 먹인 지 얼마나 됐나,
얼마나 깨어 있었나"로 이루어진다. `V2NightState`에 세 시계를 추가한다.

- `LastFeedMinute` — `FeedPreparedBottle` 성공 시 갱신
- `LastDiaperChangeMinute` — `DisposeDiaper`(처리 완료) 시 갱신
- `AwakeSinceMinute` — `TriggerWake` 시 갱신
- 셋 다 초기값 0 = "밤 시작 직전에 먹이고 갈았고, 21:00부터 깨어 있다"

`BabyClockResolver`가 경과 분과 피로 단계를 순수 조회로 제공한다.

### 졸림은 깨어 있던 시간으로 쌓이고, 과각성은 달래기를 어렵게 만든다

`FatigueSignalStage` = None / Early(45분) / Active(75분) / Overtired(105분).
`ObservationSignalId`에 정의만 되어 있고 아무도 만들지 않던 하품·눈비빔·귀 당김·
칭얼·활 모양·주먹 쥠을 이 단계에 연결한다. 과각성 구간에서는 안기·토닥임의
진정 폭에 `OvertiredComfortMultiplier`(0.7)를 곱한다. 피곤 신호를 제때 읽고
재우는 편이 이득이 되게 하는 유일한 규칙이므로 `BabyClockResolver` 한 곳에서만 준다.
근거: docs/feedback-log.md D3(책 표3, "피곤을 놓치면 과각성").

### 도달 불가능한 화면 코드는 지운다

`DrawStatusPanel`·`DrawStatusPanelTail`·`DrawActionPanel`·`DrawTab`은 호출부가 없는
죽은 가로 레이아웃이었다. 실제로 그려지는 것은 `DrawLandscapeStatusOrnaments`와
`DrawPortraitStatusOrnaments`·`DrawPortraitObservationSheet`뿐이다. 같은 화면을
두 벌 두면 어느 쪽을 고쳤는지 알 수 없어 삭제했다.

### 인트로는 정답 맞히기가 아니라 배제 절차를 가르친다

입과 손·등·기저귀 **세 곳을 모두** 눌러 확인해야 다음으로 간다. 오답 페널티는 없다.
이어서 아기띠 착용 → 주방 이동 → 분유 준비(섞기 → 식히고 온도 확인) → 복귀 수유 →
등 토닥이기 → 얕은 잠 실패 → 깊은 잠 확인 후 눕히기 → 백색소음기 → 베이비 모니터를
한 번씩 밟는다. 아이템 4종은 각각 자기 쓰임이 필요한 장면에서 처음 등장한다.
